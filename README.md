# Analyse de la survie des passagers du Titanic

## Objectif
Identifier les facteurs qui ont le plus influencé les chances de survie
des 891 passagers du Titanic.

## Données
Jeu de données public « Titanic » (bibliothèque seaborn).

## Démarche
1. Nettoyage : âges manquants estimés par la médiane par classe et par sexe
2. Analyse facteur par facteur : sexe, classe, âge, port d'embarquement
3. Croisement des facteurs et visualisations

## Principaux résultats
- 38 % des passagers ont survécu
- Femmes : 74 % de survie, contre 19 % pour les hommes
- 1re classe : 63 %, contre 24 % en 3e classe
- L'avantage apparent du port de Cherbourg s'explique par la part
  de passagers de 1re classe

## Outils
Python, Pandas, NumPy, Matplotlib
